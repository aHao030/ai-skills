# AI Skills

个人 AI 工具与技能资料库。不同来源的项目分别放在独立文件夹中，保留原始许可证、配套文件和版本记录。

| 文件夹 | 内容 | 来源版本 | 使用说明 |
| --- | --- | --- | --- |

此仓库存放项目源码。保存到 GitHub 不会自动在本机安装或启用工具，安装方法请查看对应文件夹的说明。

## 维护约定

- 各项目保留各自的来源和许可证。
- 更新时记录对应的上游提交，便于复查和回退。
- 原始技能及其依赖文件完整保留，个人说明单独存放。
- REA 的第三方 Git 子模块保留原始提交引用，并在本仓库根目录的 `.gitmodules` 中适配 `rea/` 前缀。
